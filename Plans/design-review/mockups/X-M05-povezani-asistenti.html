Podaci za povezivanje

Kopirajte ih sada. Token se prikazuje samo jednom i ne možete ga kasnije ponovo vidjeti; ako se izgubi, prekinite ovu vezu i napravite novu.

Adresa servera
Token

Token je kao lozinka: ko ga ima, radi u Vaše ime u okviru izabranog opsega. Ne šaljite ga drugima.

7

Kako povezati Claude

Claude Desktop i claude.ai

  1. Otvorite Podešavanja → Konektori → Dodaj sopstveni konektor.
  2. Upišite adresu servera iznad.
  3. Kao zaglavlje dodajte Authorization: Bearer i token.

Ako Vaš plan ne nudi polje za zaglavlje, koristite Claude Code ili sačekajte prijavu bez tokena (OAuth).

Claude Code

Pokrenite u terminalu:

claude mcp add --transport http zev-upravnik \
  https://zev.app/api/mcp \
  --header "Authorization: Bearer zev_mcp_Q7vd…"
